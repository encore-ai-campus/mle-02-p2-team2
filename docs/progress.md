## 6. 갱신 방법

작업 종료 전 본인 행과 상세 구역만 최신화하고 필요한 공동 연결 사항을 갱신한다. 다른 사람의 항목·이력을 지우지 않는다. 자세한 내용은 평가 보고서·노트북·PR에 두고 여기에는 요약과 링크를 적는다.

```text
작업: 무엇을 왜 바꿨는지
상태: 진행 중 / 구현 완료 / 검증 완료 / 리뷰 대기 / 막힘 등
검증: 실제 명령·결과·평가 범위 (미실행이면 이유)
근거: 저장소 경로 또는 PR/커밋/보고서 링크 (로컬 전용이면 표시)
남은 일: 다음 작업·다른 담당자에게 필요한 연결 사항
갱신일: YYYY-MM-DD (KST)
```

에이전트에 처음 요청할 때는 “루트 AGENTS.md와 docs/progress.md를 읽고 시작하고, 완료 전에 진행 현황까지 갱신해 줘”라고 전달한다. 파일을 읽을 수 없는 채팅 환경에는 해당 문서 내용을 직접 제공한다.
