# 데이터 명세서

수집 대상을 정하면 이 폴더에 문서별 명세를 추가합니다.
아래 항목은 초기 작성 기준이며 최종 데이터 스키마는 수집·전처리 구현 시 확정합니다.

| 항목 | 기록 내용 |
| --- | --- |
| 문서 식별자 | 문서를 구분하는 고유 ID |
| 제목 | 관리지침의 공식 제목 |
| 발행 기관 | 문서를 발행한 기관 |
| 출처 URL | 공식 다운로드 또는 게시 페이지 |
| 발행일 및 개정판 | 기준 날짜와 문서 버전 |
| 수집일 | 문서를 내려받은 날짜 |
| 파일 형식 및 경로 | PDF 등 형식과 `data/raw/` 아래 상대 경로 |
| 이용 조건 | 재사용 및 배포 조건 |
| 전처리 규칙 | 페이지, 표, 제목, 문단 처리 방법 |
| 검증 기준 | 누락, 중복 및 추출 품질 확인 방법 |

아직 수집한 문서나 확정된 명세는 없습니다.
