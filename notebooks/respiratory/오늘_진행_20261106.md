# 11/6 호흡기 담당 진행 기록

## 오늘 해야 하는 일

일정표 M4에서 호흡기 담당은 CrossDoc으로 문서별 행동을 검색하고, 반환한 그래프 관계와 원문 출처가 실제 Neo4j에 있는지 확인한다. 팀 공동 목표에는 근거가 충분하면 종료하고 부족한 부분이 있으면 다른 Tool을 추가 호출하는 사례 확인도 포함된다. ([일정표](../../교육시설_감염병_GraphRAG_최종_개발일정표_v2.0.md))

## 진행 과정과 결과

### 문서 간 검색과 실제 경로

- 질문: “보호자 연락은 문서마다 누가 하나요?” 개념: `CONTACT_GUARDIAN`.
- CrossDoc 단독 결과는 `OK`, Finding·Citation·GraphPath 각각 8개였다. 교육부·경기도·인플루엔자 시설 지침의 원문이 모두 포함됐다.
- 원문 청크 ID·문서·쪽·발췌와 Finding 참조를 DB에 대조했으며 오류는 없었다. 경로 8개도 관계 타입·방향·끝점·허용 문서 기준 오류가 없었다.
- 학교 문서의 인용 중 manifest 선정쪽수 밖은 없었다. 허용 문서 목록을 비우면 근거 없이 `NO_EVIDENCE`를 반환했다.
- 확인 실험으로 반환된 경로의 `HAS_CHUNK` 방향을 반대로 바꾸자 검증기가 잘못된 경로를 탐지했다. 이 조작은 메모리에서만 수행했다.
- 의미: 예시 질문의 출처와 경로가 실제 DB에 있다는 근거다. 답변의 모든 의미와 적용 조건이 맞는지 자동으로 보장하는 검사는 아니다.

출처: [실행 결과 JSON](m4_readonly_final_20261106.json), [재현 스크립트](m4_readonly_check.py), 기존 [Neo4j 시각화](captures/crossdoc.png).

### 메인 그래프 종료와 추가 검색

| 사례 | 질문 요지 | Tool 호출 | 결과 | 해석 |
|---|---|---|---|---|
| A | 유증상 학생 발견 시 담임·보건교사 확인 사항 | `action_search` 1회 | ANSWERED | 이 사례는 더 호출하지 않고 종료 |
| B | 홍역 잠복기와 학교 조치 | `action_search` → `disease_search` | ANSWERED | 첫 결과가 PARTIAL이라 질병 Tool을 추가 호출 후 종료 |
| E | 교육부·경기도의 보호자 연락 비교 | `crossdoc_graph_search` 1회 | ANSWERED | 문서 비교 경로를 사용하고 종료 |

세 결과의 Finding·Citation은 각각 DB와 대조해 오류가 없었고, 반환된 GraphPath에도 DB 대조 오류가 없었다. 이는 해당 세 사례의 결과이며 모든 질문에서 충분성 판정이 정확하다는 뜻은 아니다. 규칙 기반 라우터와 템플릿 답변으로 실행했으며 LLM 라우터·답변 다듬기는 검증하지 않았다. ([결과 JSON](m4_readonly_final_20261106.json))

### 수막구균 검색에서 발견한 문제와 수정

- 원인: 호흡기 로컬 별칭 사전에는 `MENINGOCOCCAL`이 있지만 현재 공통 DB에는 해당 Disease 노드가 없다. 기존 Tool은 원문 일치만으로도 그 ID를 Finding에 넣었다.
- 영향: 수정 전 메인 그래프의 “수막구균 감염증 잠복기는?” 질의는 DB 대조에서 Finding 3개가 제외돼 `INSUFFICIENT_EVIDENCE`, 인용 0개가 됐다. 전체 허용 문서로 실행한 별도 골든 Tool 조회에서도 Finding 7개가 같은 이유로 DB 검증에 걸렸다. 두 개수는 서로 다른 허용 문서 범위의 결과다. ([수정 전 골든 결과](golden_readonly_result_20261106.json))
- 수정: 검색 시 질병명 텍스트는 계속 활용하되, DB에 실제 존재하지 않는 Disease ID는 반환하지 않고 경고한다. 원문이 있으면 `PARTIAL`로 남긴다. DB 노드·공통 사전은 변경하지 않았다. ([disease_tool.py](../../src/rag/respiratory/disease_tool.py))
- 수정 후 같은 호흡기 문서 단독 범위의 메인 질의는 `PARTIAL`, Finding·Citation 각각 3개, 정답 PDF 90쪽 1위, DB 검증 오류 0건이다. DB에 노드가 없다는 경고를 유지한다. ([수정 후 결과](m4_readonly_final_20261106.json))
- 의미: 문서는 찾았는데 존재하지 않는 그래프 ID 때문에 출처까지 사라지던 문제를 막았다. Disease 노드 자체를 만든 것은 아니므로 해당 그래프 관계가 완성된 것은 아니다.

호흡기 골든 질문의 Tool 단독 결과를 실DB에서 읽기 전용으로 재조회했다. 아래 표는 수막구균 수정 후이자 괄호 처리 수정 전의 기록이다. 조건은 실행 시 DB의 전체 문서를 허용하고 기본 top_k를 쓰는 것이다. 숫자는 PDF 쪽의 Citation 순위이며, `없음`은 반환 목록에 없다는 뜻이다.

- 수정 전후 같은 조건의 질병 질문 10개에서 정답 쪽 순위는 모두 같았다. 수막구균 질문은 `OK`에서 `PARTIAL`로 바뀌었고 DB 대조 실패 Finding은 7개에서 0개가 됐다. T04의 세 문서 인용도 유지됐다. ([수정 전](golden_readonly_result_20261106.json), [수정 후](golden_readonly_after_20261106.json), [재현 코드](golden_readonly_check.py))
- R-Q2의 이전 골든 기록은 별도 시점의 독립 Graph `QueryOutput`이며 이번 `disease_search` 단독 `ToolResult`와 동일한 평가 경로가 아니다. 순위 차이를 곧바로 성능 변화로 단정하지 않는다.
- 이번 대조는 문서·쪽·DB 원문·관계 존재를 확인한 것이다. PDF 원본 이미지와 답변의 조건·예외를 문항별로 읽어 판독한 평가는 아니다. `OK`는 Tool 실행 상태이지 정답 판정이 아니다.
- R-Q2에 대해 사용자는 PDF 17·18쪽이 모두 필요하다고 확인했다. 변환본과 로컬 페이지 원본 이미지에서 PDF 17쪽(인쇄 13쪽) 하단에 교직원 항목 ①~④가 시작되고 PDF 18쪽(인쇄 14쪽)에 ⑤~⑨가 이어지는 것을 확인했다. 따라서 두 쪽을 모두 정답 근거로 유지한다. 나머지 질문의 PDF 원본은 이번에 전수 대조하지 않았다.

### 후보 순서 변경안 실험 — 적용하지 않음

직접 후보를 고를 때 기존 RRF 후보를 우선하는 대안을 메모리에서만 시험했다. R-Q2의 p18은 4위→2위, R-Q3 보조 p116은 6위→3위가 됐지만, R-F4의 p28은 5위→8개 밖, R-T1 보조 p236도 4위→8개 밖으로 밀렸다. R-Q2의 주 정답 p17은 여전히 8개 밖이었다.

다른 질문이 나빠져 이 대안은 실제 검색 코드에 반영하지 않았다. 같은 골든 문항으로 고른 실험이며, 호출을 순차 실행했으므로 DB가 고정된 엄밀한 A/B나 미사용 시험셋 평가는 아니다. ([비교 결과](golden_shadow_candidate_order_20261106.json), [재현 코드](golden_shadow_candidate_order.py))

### R-Q2 괄호 속 교직원 검색 수정

- 기존 질문 처리에서는 `학교(교직원)`이 붙은 단어로 처리되면서 `교직원` 검색어가 빠졌다. 괄호 속 단어를 분리하고 새로 찾은 단어를 기존 전문검색에도 전달하도록 수정했다. 특정 쪽이나 질문을 지정하는 규칙은 추가하지 않았다. ([검색 코드](../../src/rag/respiratory/disease_tool.py))
- 사전 실험 후 실제 코드로 전체 문서 허용·기본 top_k 조건에서 다시 조회한 결과, PDF 17쪽은 인용 8개 밖에서 7위, 18쪽은 4위에서 2위가 됐다. 두 쪽이 함께 반환되지만 17쪽은 여전히 상위 3개 밖이다. ([수정 전 결과](golden_readonly_after_20261106.json), [수정 후 결과](golden_readonly_brackets_20261106.json))
- 함께 비교한 질병 질문 10개 중 나머지 9개의 정답 쪽 순위는 같았고, T04는 필요한 세 문서가 모두 인용됐다. DB 대조에서 잘못된 Finding·Citation·GraphPath는 없었다. 이는 사용한 골든 질문들에서 관찰한 결과이며 별도 미사용 시험셋 평가가 아니다.
- 괄호를 분리하는 가설은 실제 코드 수정 전 메모리에서 먼저 비교했다. ([실험 결과](golden_shadow_question_brackets_20261106.json), [재현 코드](golden_shadow_question_brackets.py))
- 괄호 수정 후에도 CrossDoc 단독, 메인 그래프의 단일 호출·추가 호출 사례와 수막구균 `PARTIAL` 사례를 실제 DB에 다시 대조했다. 확인한 경로·인용·Finding 오류는 없었다. ([결과 JSON](m4_readonly_brackets_20261106.json))

### R-Q3 원문 확인: 등교중지 기준

사용자가 PDF 115·116·118·121쪽을 짚어 주었고, 호흡기 지침의 변환 원문을 대조했다. PDF 쪽 기준이며 인쇄 쪽은 각각 95·96·98·101쪽이다. ([변환 원문](../../data/raw/respiratory/2026년도%20호흡기감염병%20관리지침%28일부개정판%29%20복사본.md))

- PDF 115쪽: 전파 예방조치에 의심 증상자 진료 권고와 환자의 항생제 치료 후 최소 24시간 격리가 있다. 등교를 직접 언급하지는 않는다.
- PDF 116쪽: 집단발생 관리 맥락에서 진단 시 항생제 치료 시작 후 적어도 24시간까지 등교·등원 중지를 직접 명시한다. 학교 대응 맥락도 함께 제공한다.
- PDF 118쪽: 환자 관리 항목에 항생제 치료 시작 후 최소 24시간까지 자택 격리, 등교·등원·출근 금지를 직접 명시한다.
- PDF 121쪽: Q6에서 치료 시작 후 24시간까지 등교·등원·출근을 하지 않고 자택 격리한다고 직접 설명한다.
- 기존 골든 명세는 118쪽을 주 정답, 116쪽을 괄호로 두었다. 특히 116쪽도 시간 기준을 직접 명시하므로 단순히 등교중지만 언급한 근거로 축소하면 안 된다. 121쪽도 직접 답을 제공한다. 이후 8장을 추가해 세 직접 근거와 115쪽 참고 근거, 선정 범위 차이를 기록했으며 과거 평가표는 보존했다. ([골든 명세](../../data/specs/golden/respiratory.md))
- 괄호 수정 후 기존 실행 결과에서 116쪽은 6위였고 115·118·121쪽은 반환된 8개 인용에 없었다. 추가 근거를 포함한 정답 범위와 그에 맞는 검색 개선은 별도로 검토한다. ([실행 결과](golden_readonly_brackets_20261106.json))
- 네 청크의 검색 단계 추적: 115쪽은 벡터 35위·직접 후보 20위로 들어왔으나 필터 후 22위였다. 116쪽은 최종 6위였다. 118쪽은 전문·벡터 상위 64개와 직접 후보에서 찾지 못했고 본문 질병명·ABOUT 관계도 없었다. 121쪽은 벡터 15위였지만 RRF 결합 36위로 기존 후보 상위 32개 밖이었다. 이 결과는 해당 시점과 질문의 조회에 한한다. ([추적 결과](rq3_pages_trace_20261106.json), [추적 코드](golden_stage_check.py))
