# QueryInput·QueryOutput 샘플과 계약 확인

기존 [R-Q2 입력](../../tests/fixtures/respiratory/R-Q2_input.json)은 구 계약과 v2의 입력 검사에 통과했다. [기존 R-Q2 출력](../../tests/fixtures/respiratory/R-Q2_output.json)은 구 계약에는 맞지만 v2에서 필요한 `response_type`, `tools_used`, `search_rounds`가 없다. 기존 독립 Graph 실행 결과를 지우거나 수정하지 않았다.

현재 계약을 설명하기 위한 별도 예시:

- [인플루엔자 QueryInput 예시](../../tests/fixtures/respiratory/R-F1_v2_query_input_example.json)
- [인플루엔자 QueryOutput 예시](../../tests/fixtures/respiratory/R-F1_v2_query_output_example.json)
- 출처로 활용한 [기존 ToolResult](../../tests/fixtures/respiratory/R-F1_tool_result.json)

두 예시는 기존 ToolResult의 첫 Finding과 Citation을 바탕으로 **설명용으로 조립**한 것으로, 메인 그래프나 Streamlit을 실제 실행한 기록이 아니다. `tools_used`와 `search_rounds`는 1개 Tool 호출을 설명하는 가상 예시다. [v2 계약 검사기](../../src/rag/school/contract_v2_local.py)의 입력·출력 검사를 통과했다.

실제 실행 증빙은 별도 실DB·화면 시험에서 저장하고 예시와 혼동하지 않아야 한다.
