## 5. 롤백 범위 (공동 DB에 올릴 경우)
- 올리는 노드: Document 3, Chunk 26, SchoolAction 3 (우리 자료만)
- 올리는 관계: HAS_CHUNK, SUPPORTED_BY, DONE_BY, FOR_DISEASE, INSTANCE_OF
- 공유 사전: 새로 만드는 것은 SchoolRole `SCHOOL_TEACHER_IN_CHARGE`, ActionConcept `REPORT_HEALTH_CENTER` 2개뿐이다 (회의 승인). 기존 Disease·ActionConcept는 연결만 하고 수정하지 않는다.
- 되돌리기: 우리가 올린 노드 ID 목록(파일로 기록)을 기준으로 그 노드와 관계만 삭제. 다른 팀원 노드는 건드리지 않음.
- 삭제 전 확인: 대상 노드가 다른 팀원 쿼리에 쓰이는지 확인

## 6. 충돌 확인 방법 (올리기 전, 읽기 전용)
- 올릴 ID 목록(문서·청크·행동)이 공동 DB에 이미 있는지 노드 타입별로 확인
- 같은 문서를 다른 ID로 이미 올렸는지 확인 (중복 방지)
- 충돌이 있으면 올리지 않고 팀과 협의
