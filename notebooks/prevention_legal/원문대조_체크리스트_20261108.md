## 확인 방법
1. 열 이름 `PDF 쪽`은 **PDF 뷰어가 표시하는 1부터 시작하는 쪽 번호**다(책에 인쇄된 쪽 번호가 아니다). 원본 PDF는 `data/raw/prevention_legal/`에 있다.
2. 해당 쪽에서 인용문(줄바꿈·공백 차이는 무시)을 찾는다. 같은 쪽에 개정 예정본이 겹쳐 있는 곳(법 57·58쪽 제81조·제83조)은 **첫 번째(2026.10.8 시행본)** 문구를 본다.
3. 판정 칸에 PASS / FAIL / 미확인 중 하나를 적는다.
   - **PASS:** 그 쪽에서 인용 문구와 주체·조건·예외가 확인되고, 카드의 주장이 문맥과 같다.
   - **FAIL:** 문구, 쪽, 또는 의미가 다르다. 실제 문구와 실제 위치를 `차이·실제 위치`에 적는다.
   - **미확인:** PDF를 못 열었거나 판단을 보류했다.
4. 줄바꿈·공백 차이는 적어 두되 의미가 같으면 PASS다. 글자가 다르거나 빠진 것은 FAIL로 두고 위치를 적는다.
5. `인쇄 쪽` 칸은 책에 인쇄된 쪽 번호를 알 때만 적는다(없으면 비워 둔다).
6. 표 행(진단 89·104쪽 등)을 인용한 줄은 표 제목, 행, 열, 각주까지 확인한다.
