# 예방·법령 LegalSearchTool — README·발표 화면 초안 (유종혁, 2026-11-07)

> Written for: 팀 공통 README와 발표 화면에 넣을 예방·법령 부분을 정리하는 팀원. 이 파일은 초안이며, 공통 `README.md`는 건드리지 않았다. 숫자는 `data/specs/golden/prevention_legal.md` 7-23·7-24절과 같다.

## 1. 한 줄 소개
감염병예방법 신고 규정과 질병관리청 지침에서, 질문에 맞는 **법령·신고 근거**를 찾아 출처(문서·쪽·원문 구절)와 함께 돌려주는 Tool(`legal_search`).

## 2. 무엇을 하고 무엇을 하지 않는가
- 한다: 법령·지침의 문장을 그대로 인용해 근거를 붙인다. 신고 주체(의사, 학교 관리인, 보건소장 등)를 섞지 않는다.
- 하지 않는다: 근거가 없는 질문(처벌 수위 확정, 담당 범위 밖 질병 등)은 답을 만들지 않고 근거 부족으로 알린다.
- 한계: 사람이 원문을 읽고 만든 **답 카드**가 있는 질문에만 근거를 붙여 답한다. 카드가 없는 질문은 근거가 DB에 있어도 답하지 못한다(독립 문항 2/8).

uv run pytest tests/rag/prevention_legal -q
