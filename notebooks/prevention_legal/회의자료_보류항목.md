## 3. 팀이 같이 확인할 것
- **공동 DB 노드 변화**: 전체 노드는 회의 결정 시 275개, 11/5 점검 시 867개로 늘었고, 오늘 조회에서 Chunk만 1,536개였다(전체 노드 수는 다시 세지 않았다). 적재 전 충돌 확인을 날짜별로 다시 한다.
- **검색 방식 변경**: 로컬 키워드 점수에서 공동 DB의 `chunk_text` 전문 인덱스로 바꿨다. 이 인덱스는 팀원이 올린 Chunk에도 같이 걸린다. 우리 노드는 테스트 라벨로만 만든다.
- **테스트 노드 정리**: 우리가 만든 테스트 노드는 ID 목록으로만 지운다. 중복 적재는 제약 조건으로 막힌다 (노트북 20).
