# school 파일 지도 — 어떤 파일이 어떤 일을 했나

작성 11/4. 주승우 개인 경로(`school`)의 파일을 **파이프라인 순서**로 정리했다. 전체 흐름 그림의 ①~⑦ 단계와 같은 번호를 쓴다.

```
원문(data/raw) ─① 청크 만들기─▶ ② 행동 추출(LLM) ─▶ 검수 ─▶ ③ 정규화·ID ─▶ ④ Neo4j 적재 ─▶ ⑤ 검색 ─▶ ⑥ SchoolGraph run() ─▶ 평가
```

## 0. 지금 어떤 파일을 열어야 하나 (헷갈릴 때 이것만)

| 하고 싶은 일 | 여는 파일 |
|---|---|
| 새 행동 후보를 LLM으로 뽑고 **검수** | `notebooks/school/school_extract_rows.ipynb` |
| 검수 끝난 후보를 **정규화·ID 부여 → 적재 패키지** | `notebooks/school/school_normalize_bundle.ipynb` |
| 선정 쪽수 **전체 청크**를 만들어 하나의 패키지로 | `notebooks/school/school_chunks_full.ipynb` |
| 패키지를 **공통 Neo4j에 적재·검증·임베딩** | `notebooks/school/school_load.ipynb` |
| 질문 실행·**골든 질문 평가** | `notebooks/school/school_query.ipynb` |
| 코드를 읽고 싶다 | 아래 2번 표 |

**실행 순서(새 데이터를 넣을 때):** `school_extract_rows` → (검수) → `school_normalize_bundle` → `school_chunks_full` → `school_load` → `school_query`
