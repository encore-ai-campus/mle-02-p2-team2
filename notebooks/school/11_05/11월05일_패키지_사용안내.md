## 과거 참고 자료와의 관계

기존 school_learning_reference.ipynb와 11/04 지시서는 수정하지 않고 보관했다. 정규화·적재·원문 검증 부품은 계속 참고하되, 아래 설계는 오늘 v2.0으로 바꾼다.

- 전문 Graph 3개 조합 → 메인 1개 + 검색 Tool.
- 전문 QueryOutput → ToolResult, 최종 QueryOutput은 메인만 생성.
- 모든 질의에 무조건 청크 검색 선행 → 선택 Tool에 맞는 검색/실제 관계 탐색.
- v3.1이 이미 적용됐다는 전제 → 승인·실DB 상태를 먼저 확인.
- 2/3-Graph 필수 통합 → 단일 Tool 실제 호출과 관계 탐색 증빙, 이후 조건부 추가 호출.

## 실행 방법과 범위

프로젝트의 기존 Jupyter Python 커널에서 위부터 실행한다. 예시에는 표준 라이브러리와 langgraph가 필요하다. 없으면 몰래 단순 시뮬레이션으로 바꾸지 말고 프로젝트의 기존 uv 의존성과 환경을 확인한다. 이번 참고 패키지 작성 자체는 패키지 설치나 환경 파일 수정을 하지 않는다.

실행 셀은 인공 데이터와 메모리 사전만 사용한다. 외부 API, Neo4j, 실제 .env, 공식 PDF, 원본 수업 폴더는 사용하지 않는다. 실제 StateGraph 실행과 계약 흐름을 확인하는 예시이지 프로젝트 DB 검증 완료를 의미하지 않는다. 실제 근거 조회와 GraphPath 실DB 검사는 부품 지시서대로 별도 수행한다.

패키지는 팀 지시서의 개인 범위인 기존 notebooks/school 안에만 추가한다. 공통 src/common·orchestrator·ui·팀 문서와 다른 담당자 파일은 변경하지 않았다. main 커밋·푸시도 자동 수행하지 않는다.
