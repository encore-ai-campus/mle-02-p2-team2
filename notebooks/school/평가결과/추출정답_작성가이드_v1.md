## 작성 규칙

**한 행은 ‘원문에서 확인한 학교 행동 1개’다.** 아래 원문을 읽고 채우면 된다. 모델 출력이나 DB의 예측을 보고 정답을 맞추지 않는다. 이 문서의 예시는 작성법 설명이며, 표본의 확정 정답을 대신하지 않는다.

### 각 칸에 쓰는 내용

| 칸 | 무엇을 쓰나 | 입력 예 / 비워 두는 경우 |
|---|---|---|
| `#` | 해당 청크 안의 행동 번호. 행동을 추가할 때 행을 복사하고 1, 2, 3으로 늘린다. | `1` |
| `행동` | 누가 하는지보다 **무엇을 하는지**를 원문에 가깝게 쓴다. 대상·부정·예외·기한을 빼지 않는다. | `조치 결과를 보건(담당)교사에게 통보` |
| `역할` | 행동을 **수행하는 사람·조직**의 이름. ID가 아니라 한글 이름을 쓴다. | `담임교사`, `학교장`. 원문에 수행자가 없으면 **빈칸**. `보건교사에게 통보`의 보건교사는 수신자이므로 이 칸에 쓰지 않는다. |
| `근거` | **역할을 배정한 방식(`basis`)**. 인용문·출처·쪽수를 쓰는 칸이 아니다. | `EXAMPLE` / `EXPLICIT`. 역할을 비웠으면 같이 **빈칸**. |
| `단계` | 원문에서 그 행동이 속한 대응 단계. 상황을 보고 임의로 진단하지 않는다. | `예방`, `대응1`, `대응2`, `대응3`, `복구`, `전체단계`, `국가위기`, `미지정` 중 하나. 모르면 **`미지정`**. |
| `조건` | 어떤 경우·상황에 행동을 적용하는지 원문 표현으로 쓴다. | `추가 (의심)환자 발생 시`. 원문에 조건이 없으면 **빈칸**. |
| `강도` | 원문이 밝힌 행동의 강도. 역할 배정이 예시라는 것과 별개다. | `반드시`, `권장`, `재량`, `미지정` 중 하나. 강도가 불명확하면 **`미지정`**. |

역할 이름은 [학교 역할 사전](../../../src/index/school/dictionaries/roles.json)의 `name`을 사용한다. 예를 들어 원문의 `보건(담당)교사`는 주석의 역할 칸에 `보건교사`로 쓴다. 사전에 없는 수행자는 원문대로 적고 표 아래에 확인 메모를 남긴다. 예측에 맞추려고 역할을 지우거나 바꾸지 않는다.

**빈칸에는 `없음`, `-`, `null`을 쓰지 말고 실제로 비워 둔다.** 반대로 단계와 강도는 모르더라도 비우지 않고 `미지정`으로 쓴다. 표 안에 설명용 괄호나 원시 `|` 문자를 넣으면 채점 파서가 잘못 읽을 수 있으므로 긴 설명은 표 아래 `검토 메모:`에 적는다.

### `근거`: EXAMPLE과 EXPLICIT 구분

- `EXAMPLE`: 역할표·훈련 시나리오의 담당 예시, 또는 ‘학교 상황에 따라 자율적으로 정할 수 있음’이라는 단서가 적용되는 역할 배정.
- `EXPLICIT`: 예시·자율 조정 단서가 적용되지 않고, 개별 행동의 수행자를 원문이 직접 배정한 것이 확인된 경우. **법적 의무라는 뜻이 아니다.**
- 교육부 매뉴얼·경기도 가이드북의 역할 배정은 현재 온톨로지 규칙상 **기본적으로 `EXAMPLE`**이다. 표에 `담임교사`가 적혀 있다는 이유만으로 `EXPLICIT`을 쓰지 않는다. 다르게 판단하려면 개별 원문과 예시 단서의 적용 범위를 확인하고 메모를 남긴다.
- 수행자를 알 수 없으면 `역할`과 `근거`를 둘 다 비운다. 행동 자체는 적을 수 있다.

### `단계`: 입력값과 판단 기준

| 입력값 | 채점용 값 | 원문에서 확인할 내용 |
|---|---|---|
| 예방 | PREVENTION | 예방단계·평상시 대비 |
| 대응1 | RESPONSE_1 | 대응 제1단계 |
| 대응2 | RESPONSE_2 | 대응 제2단계 |
| 대응3 | RESPONSE_3 | 대응 제3단계 |
| 복구 | RECOVERY | 복구단계 |
| 전체단계 | ALL_STAGES | 모든 단계라고 명시 |
| 국가위기 | NATIONAL_CRISIS | 국가 위기경보 상황. 관심·주의·경계·심각 등은 조건 칸에 원문대로 보존 |
| 미지정 | UNSPECIFIED | 원문에 단계가 없거나 주어진 자료로 확인할 수 없음 |

청크 위에 표시된 `… > 바. 복구 단계` 등은 자동 생성된 경로이며 정답이 아니다. 이 주석지에는 질병별 체크리스트에 앞 절의 ‘복구 단계’가 이어 붙은 것으로 의심되는 항목이 있다. **해당 PDF/본문의 실제 제목을 확인하기 전에는 경로만 보고 `복구`를 확정하지 않는다.** `미지정`으로 잠정 작성하고 `검토 메모: 단계 원문 확인 필요`를 남기되, 원문 자체에 단계가 없는 경우와 확인 작업이 끝나지 않은 경우를 구별한다. 후자는 정답 확정 전 재검토한다.

### `강도`: 입력값과 판단 기준

| 입력값 | 채점용 값 | 원문 표현의 예 |
|---|---|---|
| 반드시 | MANDATORY | `반드시 …`, `…하여야 한다` 등으로 강도를 확인한 경우. 임의로 법률상 의무라고 확대하지 않음 |
| 권장 | RECOMMENDED | `권장`, `권고` |
| 재량 | DISCRETIONARY | `…할 수 있음` 등 선택을 허용하는 표현 |
| 미지정 | UNSPECIFIED | 강도를 확인할 수 없음. 단순히 `파악`, `연락`, `실시`라고 적혔다는 이유로 반드시로 만들지 않음 |

기존 안내의 `금지`는 현재 스키마의 강도 허용값이 아니었다. **금지·비권장은 행동 문장에 그대로 보존**한다(예: `헌혈 금지`, `휴업은 권장하지 않음`). 긍정 행동의 `권장`으로 뒤집지 않는다. 별도 금지 코드가 없는 현재 형식에서는 강도를 `미지정`으로 두고 `검토 메모: 금지/비권장 표현 보존, 별도 강도 코드 없음`을 남긴다. 금지 표현을 없애거나 금지 강도까지 평가됐다고 해석하면 안 된다.

### 작성 예시 A — 실제 11번 표본의 앞 두 행동

원문: `| 담임교사 | 보건학적 고위험군 보호자에게 연락, 조치 결과를 보건(담당)교사에게 통보; … |`

이 표는 대응 제3단계의 담당자별 역할표이며, 두 문서의 역할 배정 예시 규칙을 적용하는 작성 예다. 아래는 전체 정답이 아니라 원문의 앞 두 행동만 보여 준다.

```markdown
행동 없음: [ ]

| # | 행동 | 역할 | 근거 | 단계 | 조건 | 강도 |
|---|---|---|---|---|---|---|
| 1 | 보건학적 고위험군 보호자에게 연락 | 담임교사 | EXAMPLE | 대응3 |  | 미지정 |
| 2 | 조치 결과를 보건(담당)교사에게 통보 | 담임교사 | EXAMPLE | 대응3 |  | 미지정 |
```

두 번째 행의 역할도 **담임교사**다. 보건(담당)교사는 통보받는 사람이다. 원문에 남은 다른 행동도 각각 검토해 추가해야 한다.

### 작성 예시 B — 조건은 있지만 수행자는 없는 경우

설명용 문장: `추가 (의심)환자 발생 시 즉시 관할 보건소에 연락`. 이 문장 외에 수행자·단계·강도를 확정할 맥락이 없다고 가정한다.

```markdown
행동 없음: [ ]

| # | 행동 | 역할 | 근거 | 단계 | 조건 | 강도 |
|---|---|---|---|---|---|---|
| 1 | 즉시 관할 보건소에 연락 |  |  | 미지정 | 추가 (의심)환자 발생 시 | 미지정 |
```

보건소를 수행자로 쓰지 않는다. `즉시`는 시점을 설명하며, 그것만으로 강도가 반드시가 되지는 않는다.

### 작성 예시 C — 학교 행동이 없는 경우

12번 표본처럼 참고문헌 링크만 있는 청크는 다음과 같이 쓴다. 빈 행동 행은 그대로 두거나 삭제해도 된다.

```markdown
행동 없음: [x]

| # | 행동 | 역할 | 근거 | 단계 | 조건 | 강도 |
|---|---|---|---|---|---|---|
| 1 |  |  |  |  |  |  |
```

`행동 없음: [ ]` + 빈 행은 **미작성**, `[x]`는 **검토 결과 학교 행동 0개**다. 모른다고 `[x]`를 표시하지 않는다. 증상·잠복기·진단법 설명만 있으면 보통 학교 행동이 없지만, **법 조문이라는 이유만으로 제외하지 않는다.** 조문에 학교장 등의 수행 업무가 명시돼 있으면 행동이다. 교육청·보건소·의료기관의 내부 업무는 학교 행동에서 제외하고, 학교가 그 기관에 연락·보고·협조하는 행동은 포함한다.

### 분할·검토와 현재 채점의 한계

- 한 문장 안에서도 독립된 수행 행동이면 행을 나눈다. 대상·도구·조건·기한만 다른 말로 풀어 쓴 것을 별도 행동으로 부풀리지 않는다. `기침이 멈출 때까지 최소 3주 이상 격리`라면 기간을 행동 문장에도 보존한다(현재 표에는 별도의 기간 칸이 없음).
- 두 행동에 같은 조건이 적용되면 각 행에 조건을 반복한다. 원문의 `단`, `제외`, `경우`, 부정 표현도 보존한다.
- 여러 수행자가 **같은 행동 하나**를 함께 맡으면 행동 수를 늘리지 말고 역할 칸에 이름들을 적은 뒤 `검토 메모:`를 남긴다. 현재 채점은 복수 역할 집합을 정확히 비교하지 못하므로 해당 역할 점수는 별도 확인이 필요하다.
- 현재 채점 코드는 행동 문장의 문자열 유사도로 짝을 찾고, 그 짝의 역할·basis·단계·강도를 비교한다. **조건은 읽어 두지만 별도 일치율을 계산하지 않는다.** 자동 매칭 결과는 의미 정답 판정과 다르므로 결과의 짝을 재검토한다.
- 모호한 항목은 `검토 메모:`에 이유를 남기고 확정 전 재검토한다. 이 메모는 채점 코드가 읽지 않으므로 메모만 남겼다고 평가에서 자동 제외되지 않는다. 일부만 작성한 결과를 20개 전체 평가로 보고하지 않는다.
- 이 안내와 예시를 추가했어도 아래 20개 표본은 자동으로 정답 확정되지 않는다. 원문 기준의 검토·확정 후 채점한다.
