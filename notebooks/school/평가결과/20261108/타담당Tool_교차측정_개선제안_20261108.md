# 다른 담당 Tool 교차 측정과 개선 제안 (2026-11-08)

- 질문(승우 님): 다른 담당자 파트 중 성능·효율을 유의미하게 높일 수 있는 부분이 있는가? 억지로 만들지 않는다. 개선 비용을 고려해 필요성을 엄밀히 본다.
- 앞선 측정: [Tool 흐름 비용 측정](Tool흐름_비용측정_20261108.md)(학교 질문 위주 55문항).
- 이번 측정 대상: 다른 담당 골든 질문 39개.
  - 호흡기 골든 9문항(R-*). 쪽 정답 9문항.
  - 법령 골든 30문항(Q01~Q30). 쪽 정답 18문항.
- 실행 방식 세 가지(각 1회, 허용 문서는 DB 10종 전체, DB 읽기 전용)
  - main: 화면과 같은 메인 그래프
  - action: 학교 행동 Tool 단독
  - own: 질문 담당 Tool 단독(호흡기는 질병 Tool, 법령은 법령 Tool)
- 스크립트: [cross_tool_probe.py](../cross_tool_probe.py). 원자료: [cross_tool_probe_20261108.json](cross_tool_probe_20261108.json).
- 주의
  - 각 담당 Tool은 자기 골든을 보고 다듬은 부분이 있다(법령 카드는 특히 그렇다). 그래서 own 값은 독립 평가가 아니라 낙관적인 값이다.
  - 학교 행동 Tool도 학교 골든으로 다듬었다.
  - 쪽 정답(hit)은 "정답 문서·쪽을 인용했는가"만 본다. 다른 문서의 같은 내용으로 맞게 답한 경우도 miss로 센다.

## 2. 해석과 원인

1. **법령 Tool 시간의 약 89%가 DB 연결 비용이다.** `retrieve.py`의 검색 함수 5개가 매번 `connect()`로 새 드라이버를 만들고 연결 확인까지 한다. 검색 로직 자체는 0.4초 안팎이다.
2. **Q21 실패는 메인 그래프의 재탐색 규칙 때문이다.** 메인은 명시적 신호(보조 의도, `[미해결] … Tool 이름` 경고)가 있을 때만 다음 Tool을 부른다. 주 의도 Tool이 근거 없음을 내도 다른 Tool로 넘어가지 않는다. 그래서 카드가 없는 법령 질문은 막다른 길이 된다. 학교 행동 Tool은 DB 전체 문서를 검색하므로 이런 경우 답할 수 있다.
3. **Q06 실패는 라우팅 정의가 모호해서 생겼다.** 라우터는 "어떻게 다른가요"를 문서 비교(CROSSDOC)로 읽었다. 문서 비교 Tool은 두 문서(교육부·경기도)를 비교하는 Tool이고, 학교급(대학/초·중·고) 비교에는 쓸 수 없다.
4. **Q08 오답은 학교 행동 Tool(제 영역)의 검색 누락이다.** 같은 표의 다른 행(신고 시기)을 가져오지 못했다. 사례가 1건이다.
5. **질병 Tool은 자기 골든에서 빠르고 정확하다(9/9, 1.2초).** 다만 질병 사실 질문을 학교 행동 Tool로 보내도 이번 답변은 모두 맞았다. 라우팅을 바꾸면 속도는 약 2초 줄 수 있지만 정확도 이득은 이번 자료로는 보이지 않는다.
6. **법령 Tool을 일반 검색기로 바꿀 필요는 없다.** 법령 골든에서 학교 행동 Tool 단독이 13/18로 법령 Tool(11/18)보다 높다. 법 조문 원문은 이미 학교 행동 Tool과 판단 기준 조회가 찾는다. 법령 카드의 가치는 사람이 검증한 주체 구분 답(Q09·Q10·Q11·Q13 등)에 있다.

### 하지 않는 것이 나은 것

- **보조 의도 Tool 동시 호출·법령 보조 호출 생략:** 1번을 적용하면 법령 보조 호출이 약 0.4초가 되어 이득이 작아진다. 공통 계약 변경 비용이 더 크다.
- **질병 사실 질문을 질병 Tool로 더 보내는 라우팅 변경:** 이번 자료에서는 답의 정확도 차이가 없었고 속도만 약 2초 줄어든다. 발표 전에 라우터를 흔들 이유로는 약하다.
- **법령 Tool의 카드 방식을 일반 검색으로 재작성:** 학교 행동 Tool이 이미 더 넓게 찾는다.
- **법령 Tool 전문검색 개수 제한:** 0.08초 차이다.
- **질병·문서 비교 Tool 코드 수정:** 측정상 문제가 보이지 않았다.

- 2번·3번 제안의 효과는 아직 구현하지 않아 미실측이다.

### 5-3. 해석
- **법령 Tool 시간:** 1회 약 2.9초에서 1.3~1.4초로 줄었다. 6문항 실험값(0.39초)보다 큰 이유는 측정 경계 차이로 보인다(가설, 미확인). 실험값은 첫 연결을 미리 만든 뒤의 조회만 쟀고, 실서비스 경로에는 카드 원문 대조와 결과 검사가 포함된다. 전체 연결 수는 11회에서 1회로 줄었다(사실).
- **넘기기 발동 범위:** 교차 측정 39문항 중 2건(Q21·Q25)에서 발동했다. 학교 위주 55문항에서는 발동하지 않았다(Tool 순서가 전과 같다).
  - Q21: 막다른 길이 정답 원문으로 바뀌었다.
  - Q25: 상태 변화는 없고 Tool 호출만 1회 늘었다.
- **그 밖의 상태 변화는 실행 간 변동으로 본다.** 55문항에서 D01·D03·D07·S-A02·S-A04, 교차 측정에서 Q10의 상태가 바뀌었다. 모두 Tool 호출 순서와 결과가 전과 같은 문항이라, 이번 변경이 아니라 LLM 선별·충분성 판정의 실행 간 변동이다(전에도 37~38/40 수준에서 오르내렸다).
- **변하지 않은 실패:** Q06(라우팅, 3번 보류)과 Q08(학교 행동 Tool의 표 행 누락)은 그대로다.
