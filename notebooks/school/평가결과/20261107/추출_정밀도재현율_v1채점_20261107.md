# 행동 추출 정밀도·재현율 — 주석지 v1 채점과 주석지 v2 (2026-11-07)

목적: 발표의 "적재 품질" 파트에 행동 추출 정확도를 넣는다. 승우 님이 작성한 주석지 v1(11/05 청킹 기준)으로 **그 당시 적재본**을 채점하고, 현재 청킹(v4.1) 기준 주석지 v2를 만든다.

상태: 채점 완료(DB 접속 없음, 로컬 적재 패키지로 계산). 주석지 v2는 생성만 했고 확정은 승우 님 몫이다. 로컬 미커밋.

## 1. 무엇과 무엇을 비교했나

| 항목 | 값 |
|---|---|
| 정답 | [주석지 v1](../추출정답_주석지_v1.md), 작성 주승우(눈가림: 모델 출력을 보지 않고 원문만 보고 작성) |
| 표본 | 20청크(seed 1105, 11/05 청크 1,131개에서 문서×종류 4층 무작위 12 + 추출 입력 표 행 8). [표본 JSON](../../../../data/specs/golden/school_extraction_sample_v1.json) |
| 예측(그 당시) | 11/05 적재 패키지 `full_20261105T032224_612625Z/bundle.json`(load_ledger 11/05 03:22 UTC 적재, 행동 438개) |
| 예측(현재) | 현재 적용본 `service_migration_20261106T030252_317651Z/effective_bundle.json`(v4.1, 행동 438개) |
| 채점 | [extraction_score.py](../extraction_score.py). 정답 단위 (청크, 행동 1개), precision = TP/예측, recall = TP/정답 |

**그 당시와 현재의 추출 결과는 사실상 같다.** 두 적재본의 행동 438개를 비교하면 ID·문장·강도·근거 청크·역할 배정이 모두 같고, 단계 값 1개만 다르다(11/06 검수 반영). 그래서 v1 주석으로 잰 값은 현재 버전에도 그대로 적용되며, 실제로 두 적재본의 채점 결과가 같았다. 바뀐 것은 청크의 **원문 글**(표 제목·본문 분할)이다.

## 2. 이번에 고친 채점 코드

- `--bundle`: DB 대신 적재 패키지의 행동을 예측으로 쓴다(그 시점 재현용).
- `--sheet`, `--sample`: 다른 주석지·표본으로 채점.
- `--overrides`: 사람이 검토한 짝(JSON)을 쓴다. 검토 짝: [school_extraction_overrides_v1.json](../../../../data/specs/golden/school_extraction_overrides_v1.json).
- 잠정 표시 처리: 주석지의 `행동 없음: [x?]`와 칸 끝 `?`를 이전 코드는 '미작성'으로 읽어 빠뜨렸다. 이제 적힌 값대로 읽고 '잠정'으로 표시해, **전체**와 **잠정 표시 없는 청크만**을 함께 낸다. 행동 칸이 `?`뿐이면 '판정 보류'로 뺀다.
- F1 열 추가.

## 3. 결과

### 3-1. 대표값 (검토 짝, 그 당시 적재본)

|---|---|---|---|
| **전체** (채점 18청크, 정답 행동 14개) | **0.91 (10/11)** | **0.71 (10/14)** | **0.80** |
| 무작위 표본(전 과정) | 0.86 (6/7) | 0.67 (6/9) | 0.75 |

| 본문 | – (예측 0) | 0.00 (0/1) | – |
| 잠정 표시 없는 청크만(11청크) | 0.90 (9/10) | 0.90 (9/10) | 0.90 |

| 짝지어진 행동의 속성 | 일치 |

95% 신뢰구간(Wilson, 참고): precision 0.62~0.98, recall 0.45~0.88. **표본이 작아 구간이 넓다.**

### 3-2. 자동 짝(글자 유사도)과 검토 짝의 차이

| | precision | recall | F1 |
|---|---|---|---|
| 자동 짝(Dice ≥ 0.45, 기존 스크립트 규칙) | 0.55 (6/11) | 0.43 (6/14) | 0.48 |
| 검토 짝 | 0.91 (10/11) | 0.71 (10/14) | 0.80 |

자동 짝이 놓친 4쌍은 같은 뜻인데 문장 길이가 달랐다. 짝 판정은 Claude가 했고 **승우 님 확인 전**이다(근거는 overrides JSON의 `reasons`).
- 주석 "위생수칙 교육" ↔ 모델 "사회적 취약계층에게 위생수칙을 교육한다." (생활지도도 같은 경우)
- 주석 "최소 3주 이상 격리" ↔ 모델 "격리" + 기한 칸 "기침이 멈출 때까지 최소 3주 이상"
- 주석 "접촉자 조사"(표의 구분 칸 이름) ↔ 모델 "교내 동선별 접촉자 파악을 위해 학교 도면을 파악한다"(내용 칸)

### 3-3. 틀린 것 (검토 짝 기준)

| 종류 | 청크 | 내용 | 원인(판단) |
|---|---|---|---|
| 놓침 | `gyeonggi…p0185:t01r06` | "학급 내 학생 자리 배치도 명단 및 담임(수업)교사 파악" | **추출 입력이었는데 모델이 0개 추출.** 진짜 누락 |
| 놓침 | `gyeonggi…p0238:b04` | "환기 및 소독 완료"(학교장) | 본문 청크라 추출 대상이 아님(11/05 추출은 표 행만) |
| 놓침 ×2 | `moe…p0038:t01r04` | 교육청의 확인·대비 2개 | 수행자가 교육청. 가이드는 교육청 내부 업무를 학교 행동에서 제외한다 → 주석을 '행동 없음'으로 확정하면 recall 0.83(10/12) |
| 더 뽑음 | `moe…p0066:t03r02` a23 | "급식 제공 방안을 마련하기 위해 … 협의" | 주석 1행을 모델이 2행(급식/복지 연계)으로 나눔. 단위 차이 |
| 근거 불일치 5건 | `moe…p0066:t03r02` | 주석 EXPLICIT ↔ 모델 EXAMPLE | 온톨로지 규칙이 학교 문서 역할표를 EXAMPLE로 고정한다. 가이드 기본값도 EXAMPLE. 주석 쪽을 확인할 일 |

### 3-4. 채점에서 뺀 것

- `moe…p0056:t01r02`: 미작성(행동 없음 표시도, 행동 행도 없음).
- `gyeonggi…p0171:t01r04`: 행동 칸이 `?`(판정 보류). 모델은 "결핵역학조사 대상자들의 학부모에 대한 설명회 시 적극 협조"를 뽑았다. 행동으로 확정하면 precision·recall이 함께 오른다.

## 4. 해석

- **사실:** 표 행에서 모델이 뽑은 행동은 대부분 맞았다(precision 0.91). 짝지어진 행동의 역할·단계·강도는 모두 일치했다.
- **사실:** 재현율의 손실은 ① 본문을 추출하지 않은 설계, ② 추출 입력 표 행 1개의 진짜 누락, ③ 주석 기준(교육청 행)에서 왔다.
- **판단:** 발표에서는 "표 행 추출 정밀도 0.91·재현율 0.77(표본 20청크, 1인 주석)"과 "본문은 추출하지 않음(설계 한계)"을 나눠 말하는 것이 정확하다. 검색 진단에서 본 "정답 근거에 행동이 없는 문항 9/34"와 같은 원인이다.
- **한계:** 정답 행동 14개·채점 18청크로 작다. 주석 1인. 잠정 표시 7청크. 짝 검토는 Claude.
