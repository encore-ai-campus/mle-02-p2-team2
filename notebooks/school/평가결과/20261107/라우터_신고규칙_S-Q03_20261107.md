# 신고 질문 라우팅 규칙과 S-Q03 (2026-11-06 밤 ~ 11-07)

선행: [LLM 라우터](../20261106/LLM라우터_20261106.md), [법령 S-L01 반영](../20261106/골든_S-L01_반영_20261106.md), [라우터·후보 선별 진단](../20261106/라우터_후보선별_진단_20261106.md).
"성홍열도 학교장이 보건소에 신고해야 하나요?"(S-Q03)가 법령 Tool로만 가서 근거 없이 끝나는 원인을 분석하고, ② 전에 할 일을 처리했다.

## 1. 분석 (사실)

- 골든 S-Q03의 정답 근거 2개(C11·C12)는 모두 **경기도 가이드북**이다. C11 "신고가 필요한 법정감염병인 경우 학교장은 관할 보건소장에게 신고"는 DB에 학교 행동으로 추출돼 있다. 그런데 기대 Tool은 `legal_search`였다.
- 같은 질문 4개를 3가지 경로로 실행(실DB, 현재 법령 Tool):

| 질문 | 법령만(당시 현재) | 학교 행동 먼저 + 법령 보조 | 법령 먼저 + 학교 행동 보조 |
|---|---|---|---|
| S-Q03 성홍열 신고 | 근거 부족 | PARTIAL(인용 9) | PARTIAL(인용 9) |
| 결핵 학교장 신고 | 근거 부족 | PARTIAL(10) | PARTIAL(10) |
| S-A04 홍역 신고 공문 | 근거 부족 | PARTIAL(10) | PARTIAL(10) |
| S-L01 감염병예방법상 신고 의무 | PARTIAL(1, 법만) | PARTIAL(11) | PARTIAL(11) |

- 법령만 부르면 카드가 없을 때 막다른 길이다. 학교 행동을 먼저 부르면 학교 행동 Tool이 "법정 신고 의무는 학교 문서만으로 확정할 수 없다 → 법령 확인 필요"를 남겨 법령 Tool도 이어서 호출된다.
- 법 조항을 직접 묻는 S-L01에 학교 행동까지 붙이면 인용이 1개 → 11개로 늘어 학교 행동 근거가 잡음이 된다.
- 8종 목록 청크(`b01`)는 질문 표현에 따라 검색 순위가 크게 다르다(hybrid, 후보 30개).

| 검색 질문 | b01 순위 |
|---|---|
| 성홍열도 학교장이 보건소에 신고해야 하나요? | 30위 밖(후보 60개에서 60위) |
| 성홍열은 학교장이 보건소에 신고해야 하는 법정 신고 대상인가요? | 30위 밖(후보 60개에서 36위) |
| 학교장이 신고해야 하는 법정감염병 종류 | 10위 |
| 신고가 필요한 법정감염병 종류 신고방법 법적근거 | 6위 |

→ 병명을 넣은 질문으로는 목록형 근거가 안 잡히고, 개념 수준의 문서 용어 질문은 잡힌다. **② multi-query의 근거.**

### 개별 확인 (실DB·실LLM)

- **S-Q03:** PARTIAL. 법령 NO_EVIDENCE에도 학교 문서 근거(인용 1/2)가 남는다. 답변 요지는 다음과 같다: "성홍열이라는 이유만으로 학교장이 신고해야 한다고는 확인되지 않습니다. 경기도 가이드북은 신고가 필요한 법정감염병인 경우 학교장이 관할 보건소장에게 신고하도록 안내합니다. ※ 확인하지 못한 부분: 성홍열이 해당하는지 여부." 정직하지만 8종 목록(b01)은 인용하지 못해 "목록에 없음"까지는 말하지 못한다.
- **"수족구는 어른한테도 옮나요?":** 수림님 수정 후 OK(8 Finding). 답변은 "네, … 사람 간 전파되므로 어른에게도 옮을 수 있습니다". **근거는 '사람 간 전파'까지이고 '성인'은 근거에 없다.** 한 단계 더 나아간 추론이 검사기를 통과했다(숫자·주체·강한 표현 검사 밖).
