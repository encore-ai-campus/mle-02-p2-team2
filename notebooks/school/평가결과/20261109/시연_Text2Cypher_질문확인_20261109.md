# 시연 질문 확인: Text2Cypher (2026-11-09)

- 목적: 발표 25쪽(시연)의 질문 두 개가 시연 화면에서 실제로 동작하는지 확인한다.
- 시연 화면: 송수림 님의 [Text2Cypher 시연](../../../respiratory/text2cypher_demo.ipynb)(질문 → LLM이 Cypher 생성 → 실행 전 검사(EXPLAIN, 읽기 전용) → 읽기 실행 → 그래프). 운영 서비스(메인 LangGraph)와 분리된 개발자용 시연이다.
- 방법: 노트북과 같은 함수·같은 순서(`generate_cypher` → `validate_cypher` → `execute_cypher`)를 스크립트로 호출했다. DB는 읽기만 했고, 노트북이 쓰는 스키마 파일과 평가 기록 파일에는 쓰지 않았다. 질문마다 2~3회 실행했다(생성은 LLM이라 실행마다 달라질 수 있다).
- 한계: 한 PC에서의 실행이고 모델·DB 상태는 11/09 기준이다. Aura 화면에서 그래프를 보는 단계는 확인하지 않았다(송수림 님이 E01로 확인한 기록이 있다).

## 3. 해석

- **사실:** 캔버스 25쪽 첫 질문은 이 시연 화면에서 거부된다. 질문 끝의 "…은 무엇인가요?"가 "해야 할 일과 근거"를 묻는 서술형이라, 모델이 여러 조회를 합치는 `CALL … UNION`을 만들기 때문이다(가설: 문장 형태가 원인이고, 확정하지는 못했다). "…그래프로 보여줘" 형태로 바꾸면 안정적으로 통과했다.
- **사실:** "등교중지 실시·통보 개념에 연결된 행동과 근거 문서를 그래프로 보여줘"는 3/3 같은 결과였고, 발표 12쪽의 "개념 하나에 문서 6종의 행동 14개"와 같은 모양(행 14개)이다.
- 질문에 개념·질병 이름이 들어가면 생성이 안정적이고, 일상 문장형 질문은 불안정했다(가설).
- Text2Cypher 결과는 근거 인용을 대신하지 않는다(시연 문서의 원칙). 이 시연은 그래프 구조를 보여 주는 것이다.
